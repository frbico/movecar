第一步 · 网站与 TURN 地址

网站 HTTPS 由现有 1Panel / Nginx / Caddy 反向代理；TURN 域名仅需要 DNS A 记录指向服务器 IP，不要创建 HTTP 反向代理。

网站反向代理目标：http://127.0.0.1:8888；同 Docker 网络也可使用 http://movecar:8888。

第二步 · Firebase 消息与来电

选择 Firebase 的 Admin SDK 服务账号 JSON 上传；后台不回显私钥，APP 仍保留现有 Firebase 客户端配置。

已经导入 Firebase 的旧服务器可直接点击「下一步」。

第三步 · TURN TLS 稳定性增强

TURN 在 3478 使用 UDP/TCP；turns:turn.ssxi.de:5349 是网络限制较严时的 TLS 备用路径，不是一个需要 HTTP 反代的网站。

优先推荐自动复用现有网站泛域名证书。 可以让安装后的宿主机助手查找当前网站证书；或填写服务器证书目录，自动同步续期。无需重新向 Let's Encrypt 申请。

也可手动上传（如果不想授权目录读取）：

TURN UDP/TCP 无需证书；推荐启用 TLS 5349 提高受限网络接通机会。

开放端口清单（云服务器安全组需要手动配置）

主机防火墙会尝试自动放行。你还需要在云服务商控制台将以下端口对公网开放；网站反代后端 8888 不需要开放。

协议端口 / 范围用途
UDP3478STUN / TURN
TCP3478TURN TCP 备用
UDP49160–49191媒体中继，32 个端口整段开放

TCP 8888 是本机反向代理目标，不要添加公网入站规则。
